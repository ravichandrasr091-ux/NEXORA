05 / SENSOR CONFIGURATION

Configure BLE sensor profiles

Use the Bluetooth SIG Environmental Sensing profile or save a device-specific GATT mapping. Settings stay in this browser.

Configure GATT service and sensor characteristics
Enter a 16-bit SIG UUID (such as 181A), a Bluetooth SIG alias (environmental_sensing), or a full 128-bit UUID. Configure a format and read/notify mode per characteristic.

Available services and characteristics are enumerated only after the device grants GATT access. Sensor hardware must be read by device firmware and transmitted over BLE. NEXORA does not infer a sensor model or send control commands.

06 / SETTINGS AND COMPATIBILITY

Local by design

Configure profiles locally and inspect real device capabilities before relying on telemetry.

⌑
No supported controls reported

The current ESP32 profile exposes read/notify sensor characteristics only. No writable command or acknowledgement characteristic is configured, so output controls are unavailable.

READ-ONLY PROFILE
Browser Bluetooth limitations

Web Bluetooth is BLE GATT only; it cannot access Bluetooth Classic SPP. It requires HTTPS, a compatible browser, a user gesture, and this page must remain open. The browser does not expose a universal BLE scan list or RSSI for arbitrary devices.

Telemetry and historical samples stay in local browser storage. Nothing is sent to a cloud service. Native Android software can add Bluetooth Classic support separately; the website does not claim that capability.
