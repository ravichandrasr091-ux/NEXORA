04 / SENSOR MANAGEMENT

Configure a read-only profile

Map numeric BLE characteristics to sensor names and units. Settings stay on this device.

Configure GATT service and sensor characteristics
Each configured characteristic must send a UTF-8 numeric value and support BLE notifications. Use the actual UUIDs from your ESP32 firmware.

This profile does not discover physical I²C/SPI sensors, parse arbitrary JSON, or send commands. The ESP32 firmware must read sensors and publish their values over BLE.
